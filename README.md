# 🎮 Rock Paper Scissors Game

A classic, interactive desktop Rock-Paper-Scissors game built using Python and Tkinter. It features a sleek dark-mode user interface, emoji visuals, real-time score tracking, and smooth round-by-round gameplay against a computer AI.

---

## ✨ Features

- **Modern Dark Theme UI:** Designed with a clean, eye-friendly dark aesthetic.
- **Interactive Emoji Controls:** Make your move easily using dedicated buttons for Rock (`🪨`), Paper (`📄`), and Scissors (`✂️`).
- **Computer AI:** Automatically generates randomized choices for the computer opponent every round.
- **Real-time Score Tracking:** Keeps continuous track of player wins versus computer wins across multiple rounds.
- **Score Reset Option:** Easily wipe the scoreboard clean whenever you want to start a new series.

---

## 🚀 Technologies Used

- **Python** (v3.x recommended)
- **Tkinter** (Standard Python GUI library)
